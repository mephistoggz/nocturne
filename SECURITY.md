# Reporting a security vulnerability

If you find a security issue in Nocturne, [send a private report to the maintainer](https://github.com/mephistoggz/nocturne/security/advisories/new). This channel keeps the details private while the issue is investigated.

Include the Nocturne version or commit, your macOS version, the steps that reproduce the issue, and what data or permissions could be affected. For sign-in or music-library issues, redact cookies, access tokens, account identifiers, and personal library data from logs and screenshots.

Use [GitHub Issues](https://github.com/mephistoggz/nocturne/issues) for ordinary bugs and feature requests. Keep details of unpatched vulnerabilities in the private report.
